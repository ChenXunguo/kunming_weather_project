## 五、遗留建议（未改动，避免越界）

1. **密钥轮换**：如仓库曾公开（GitHub 等），请轮换 OpenWeatherMap Key、数据库密码、SMTP 授权码；
2. **实况数据积累**：模型训练需 30+ 条实况数据，若想更快看到预测效果，可把 `.env` 的 `COLLECT_INTERVAL` 调为 3；
3. **旧模型清理**：`models/` 与 `model_cache/` 下有多份历史 pkl，建议保留最新、清理过期文件（本次未删，避免误删）；
4. **Dockerfile 版本**：Dockerfile 基于 python:3.9-slim，与本地 3.14 不一致，建议统一为 3.12+；
5. **低优先级死代码**：`worker_pool.wait_for_dependencies` 未被调用、`http_monitor.stop()` 未真正停服（daemon 线程，进程退出即回收），可按需清理。
